# 🎯 Emoji 猜猜看

一个纯前端（零依赖、零构建）的 emoji 版推理小游戏。

打开 `index.html` 即可开始玩，不需要装任何东西，也不需要起服务器。

## 玩法

1. 每局会从 24 个 emoji 的池子里**随机抽出「候选栏数量」个 emoji**，谜底再由这些候选随机生成，所以每局都不一样。
2. 你在「待选栏」里按顺序点选 emoji 摆进槽位；点一下任意槽位（**空位也行**）可以把它 **🔒 锁定**在这个位置。
3. 选满后点「判定」（勾选了「选满自动判定」则选满即判），本次组合会进入**记录框**。
4. 判定结果给出两个数字：
   - `✅ 命中`：位置和 emoji 都正确；
   - `🔄 错位`：emoji 出现在谜底里，但位置不对。
5. 用记录框里的历史推理出唯一答案，全部命中即获胜，弹出**记分牌**并撒彩带。

## 默认规则

- **候选栏数量 = 谜面长度**（`跟随谜面` 默认开启），且**不允许重复**：
  也就是说每个候选 emoji 恰好出现一次，本质是在猜一个「排列」。
- 谜面长度默认 6，可调范围 3~20。

## 锁定（🔒）

锁的是**位置**，不是某个 emoji：

- 点一下任意槽位（**空位也可以**）→ 把这个位置钉住（金色边框 + 🔒 角标），再点一次解锁；一局之内随时都能锁定 / 解锁。
- 锁定的**空位**填 emoji 时和普通空位一样会被填上，填进去之后这个 emoji 就受该位置的锁定保护。
- 锁定位置上的 emoji：**撤销、清除、判定失败都不会动它**；判定后它按原位置保留，其余未锁定的槽位才会被清空。
- 所有位置都锁住且都有 emoji 时，撤销 / 清除按钮会置灰（确实没有可操作项），先点槽位解锁。
- 新开一局（改难度、点「🎮 新游戏」）会清空槽位并解除全部锁定。
- 想改中间某个未锁定的位置：先「撤销」（从后往前跳过锁定位置）或「清除」，再重新选。

## 界面

```
┌ 难度标签（点它开设置）              ⚙️ 设置   🎮 新游戏 ┐
│ 猜测 3 次   用时 00:42   已选 2 / 6   🔒 锁定 1        │
│ 模式提示：每个 emoji 恰好出现一次…                      │
│ ① ②🔒 ③ ④ ⑤ ⑥  ← 槽位（点已填的可锁定/解锁）          │
│ [撤销] [清除已选]                    [判定]            │
│ 待选栏：🅰 🅱 🅲 …（点一下加入）                        │
└────────────────────────────────────────────────────────┘
                                    右侧 / 手机下方：📋 记录框
```

- 顶部「难度标签」和「⚙️ 设置」都打开设置弹窗；「🎮 新游戏」只重掷谜底，不改难度。

## 设置弹窗

所有难度设置都收在弹窗里，按分类逐项列出：

| 设置 | 说明 |
| --- | --- |
| 谜面长度 3~20（默认 6） | 谜底有几个 emoji，也决定槽位数量 |
| 候选栏数量 3~24（默认跟随谜面） | 待选栏给几个 emoji；关闭「跟随谜面长度」后可手动调，范围自动夹在 `谜面长度 ~ 24` |
| 跟随谜面长度（默认开） | 候选栏数量始终等于谜面长度 |
| 允许重复（默认关） | 打开后谜底可能出现重复的 emoji，候选按钮上显示 `×n` 计数 |
| 选满自动判定（默认开） | 关掉后需要手动点「判定」，适合想反复调整的玩家 |

- 弹窗内的改动是**暂存**的，点「应用并重开」才生效并重新开局；点「取消」、点遮罩或按 `Esc` 会丢弃改动。
- 如果本局已经猜过，弹窗里会提示「应用新难度会重新开局并清空记录框」。
- 其他：计时与猜测次数实时显示；**最佳成绩按难度分开记录**（长度 + 候选数 + 是否重复），存在 localStorage；「复制战绩」可把整局记录导出成文本。
- 快捷键：`Backspace` 撤销、`Enter` 判定、`Esc` 清空（弹窗打开时 `Esc` 关闭弹窗）。

## 界面与动画

- 响应式：PC 上是「左游戏 + 右侧粘性记录框」两栏；手机 / 窄屏自动变单栏，槽位、候选栏、按钮尺寸用 `clamp()` 自适应并支持刘海安全区，触屏设备会关掉 hover 残留效果。
- 动画：槽位弹入、候选按钮按压反馈、锁定角标旋转弹入、记录行滑入、全错时棋盘抖动、命中时绿色脉冲、胜利时彩带 + 谜底逐格翻出 + 槽位波浪、弹窗弹入/淡出。
- 尊重系统设置：开启「减少动态效果」时全部动画停用。

## 文件结构

```
index.html          页面结构（游戏区 / 记录框 / 设置弹窗 / 记分牌）
css/style.css       深色主题、PC+手机响应式布局、全部动画关键帧
js/emoji-pool.js    候选 emoji 池数据（单码位 emoji，含中文名）
js/game-core.js     纯逻辑：抽候选、生成谜底、命中/错位判定、计分（不碰 DOM）
js/app.js           交互层：渲染、事件、localStorage、动画、设置与记分牌弹窗
```

`game-core.js` 不依赖 DOM，可以直接被测试脚本加载来做单元测试。
